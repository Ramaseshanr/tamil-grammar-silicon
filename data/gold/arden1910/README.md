# Arden 1910 — rule index

`paragraphs.json` — **589 numbered paragraphs, §1–663**, from *A Progressive Grammar of
Common Tamil*, Rev. A. H. Arden (1841–1897), 1910.

## Provenance and licence

`archive.org/details/progressivegramm00ardeiala`. **Public domain** — the author died in
1897 and the edition is 1910. This is the only one of the project's four reference sources
that is both freely redistributable *and* independently authored, which is what makes it
admissible as a rank-2 authority in `docs/METHOD.md`.

### The vocabulary oracle is the wrong instrument here

69.2% understates it badly on the conjugation pages. Leaf 86's "misses" are
**அமர்ந்தேன், தவழ்ந்தேன், தேர்ந்தேன், தகர்த்தேன், தாழ்த்தேன், தகர்க்கிறேன், தாழ்ப்பேன்** —
all correct Tamil 1sg forms, absent from Wikipedia because an encyclopaedia does not say
"I crawled". The oracle conflates OCR error with legitimate rarity.

The right oracle is **our own grid**, which is also what makes Arden a second gold:

| | distinct Arden forms | also generated by us |
|---|---:|---:|
| conjugation, leaves 77–88 | 436 | **295 — 68%** |
| declension, leaves 39–51 | 259 | 82 — 32% |

68% mutual confirmation between a 1910 grammar and a Naṉṉūl-derived engine is the strongest
independent check this project has had. The declension figure is low because those pages
carry more table-border noise (`அஅமரங்களே`, `அஅமரங்களால்`), not because the forms disagree.

### What the disagreements are worth — one worked case

Arden gives **அமருகிறேன் / அமருவேன்** for அமர்; we generate **அமர்கிறேன் / அமர்வேன்**. Both
agree on the past, அமர்ந்தேன். So Arden treats அமர் as taking the உ-linking stem before
கிற்/வ் while ThamizhiMorph classes it C11 (strong) without it. **That is a class
disagreement to adjudicate against Naṉṉūl**, and it is exactly the kind of thing a single
gold cannot surface.

Inspecting the same paradigm also exposed a defect of ours: `caus=வி + fut=வ்` still yields
**அமர்விவேன்**, where `caus=ப்பி` correctly yields அமர்ப்பிப்பேன். That is the very error
already corrected for பாடு ("பாடுவிவோம் is wrong, but பாடுவிப்பேன் is correct") — `fix_verb_grid.py`
Defect 3 fixed it only for 1pl/2sgh/2pl, so it survives in the வி-causative elsewhere.
Recorded, not yet fixed.

## ⚠️ The original archive.org OCR gives rules, NOT forms

The archive.org OCR recovers the English prose cleanly and **destroys the Tamil script**:

```
  §145  "The particle ^}«ir may be inserted before the casal affix of any case of any
         noun, except the nominative and vocative … the dative adds (5 only (110),
         and final ear is changed into p (94)."
```

`^}«ir` is இன், `(5` is கு, `ear` is ன், `p` is த். Elsewhere மரம் appears as `tcTti`,
மரத்துக்கு as `u>jpgi&(3)`, மரத்தில் as `LDJpjsleo`.

So Arden can be read as an **independent statement of the rules**, which is exactly how this
project already used it — §110, §129–130, §134 and §145 were rule statements that our own
code then applied to generate forms (`tools/patch_gold.py`). It **cannot** supply a second
*form* gold to grade against. That would need the Tamil re-OCR'd with a Tamil engine, or
transcribed by hand.

This corrects a recommendation made before the source was inspected: digitising Arden's
paradigm tables to obtain a second external gold is **not achievable from this scan**.

## Gaps

74 of §1–663 are missing, where the OCR lost the paragraph number or the number was
swallowed into surrounding text. The five paragraphs this project cites — **110, 129, 130,
134, 145** — are all present.
